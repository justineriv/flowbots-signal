# FlowBots.ai — Signal

Light editorial system. Warm paper, deep navy ink, geometric headlines. Consultancy-grade and calm.



**Open the link and browse it like the real site.** The navigation works — Solutions,
Industries, Automations, Pricing, About and Blog all lead to the built pages.

There is also a preview harness at **`preview.html`** if you want to jump straight to a
specific template or check the tablet and mobile rendering side by side.

| Blog Index | flowbots.ai/blog |

## What is real and what is not

- **Copy is taken from the live flowbots.ai** and used as-is. Nothing was invented.
- **The assessment form validates and confirms, but is not connected to a backend.** No lead is delivered anywhere until an endpoint is added.
- **No analytics ID is included.** Tracking events are wired and fire through `dataLayer`/`gtag` the moment GA4 or GTM is added to the page head.
- **Animation is confined to the homepage hero.** Every other page is static.
- Founder bio content beyond the About-page text is marked with bracketed placeholders.
